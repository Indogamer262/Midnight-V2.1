# Soal
Untuk setiap nomor, lakukan ANOVA (Single Factor) untuk menentukan apakah semua rata-rata populasi dari tiap sampel adalah identik atau tidak.

ANOVA TABLE

| Source of Variation | df  | Sum of Squares | Mean square |    f     |
| ------------------- | :-: | :------------: | :---------: | :------: |
| Treatments          |  2  |    0,060853    |  0,030427   | 0,986597 |
| Error               | 12  |    0,37008     |   0,03084   |          |
| Total               | 14  |    0,430933    |             |          |
Karena $f < F_{0.01,2,12}$ &nbsp;maka $H_0$ diterima
