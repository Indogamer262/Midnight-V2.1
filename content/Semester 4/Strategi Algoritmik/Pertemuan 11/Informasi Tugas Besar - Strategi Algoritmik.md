# Our Draft

Draft Plan Tugas Besar kita:

1. Konsep Aplikasi
	- Berbasis Static Website (HTML, CSS, JavaScript). No server/database, biar praktis.
	- Fitur wajib: Input data barang (n >= 8), kapasitas W, proses Backtracking (DFS) + Pruning, output tabel barang, solusi optimal, serta statistik (jumlah node & waktu eksekusi).

2. Strategi & Fokus Utama
	- Fokus utama kita ada di LAPORAN. Kita bakal lakukan testing massal dengan banyak skenario data.
	- Menampilkan banyak grafik analisis di dalam laporan (misal: grafik jumlah barang vs jumlah node, waktu eksekusi dengan vs tanpa pruning, dll).

3. Garis Besar Langkah Kerja
	- Tahap 1: Bikin core algoritma backtracking & fungsi pruning di JS.
	- Tahap 2: Bikin UI input/output sederhana menggunakan HTML & CSS.
	- Tahap 3: Running test sebanyak-banyaknya untuk ambil data statistiknya.
	- Tahap 4: Susun Laporan (Deskripsi persoalan, deskripsi solusi, grafik hasil pengujian, screenshot UI, dan lampiran kode).

Rincian detail timeline dan pembagian tugasnya bisa kita obrolin bareng-bareng nanti pas kumpul. Sila beri masukan ya!
